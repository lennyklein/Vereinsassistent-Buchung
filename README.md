# 📊 Vereins-Buchhaltungs-Assistent

Ein moderner, lokaler Web-Buchhaltungsassistent für Vereine und kleine Organisationen, entwickelt mit **Flask (Python)**, **SQLite** und einem responsiven **Dark-Themed UI**.

## ✨ Features

* **Transaktions-Erfassung:** Einfaches Buchen von Einnahmen und Ausgaben mit Datum, Zweck, Kategorie und Betrag.
* **Live-Finanzübersicht:** Dynamische Statistik-Karten für Gesamteinnahmen, Gesamtausgaben und den aktuellen Saldo (Gewinn/Verlust).
* **Steuerberater-Export:** Automatischer CSV-Export aller Buchungsdaten für den unkomplizierten Export an den Steuerberater.
* **Sicherer Reset-Modus:** Integrierte Funktion zum Zurücksetzen des Jahresabschlusses inklusive Sicherheitsabfrage, um versehentliches Löschen zu verhindern.
* **Modernes UI:** Dunkles, aufgeräumtes Design im modernen Dashboard-Stil.
